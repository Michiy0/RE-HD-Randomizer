RANDOMIZER RESIDENT EVIL HD REMASTER — version Linux / Steam Deck
================================================================

L'application tourne nativement sous Linux (sans Proton). Le jeu, lui, tourne avec Proton
comme d'habitude.

SUR STEAM DECK
1. Passe en mode Bureau (bouton Steam → Alimentation → Passer au Bureau).
2. Extrais cette archive où tu veux, par exemple dans ton dossier personnel.
3. Si besoin, rends le fichier exécutable : clic droit sur RandomizerREHD-linux →
   Propriétés → Permissions → coche « Est exécutable ».
4. Double-clique sur RandomizerREHD-linux.
   Le jeu est trouvé automatiquement dans ta bibliothèque Steam (sinon « Parcourir… »).
5. Clique « Installer la DLL ».
6. Clique « Copier » à côté de l'option de lancement, puis dans Steam :
   Resident Evil → Propriétés → Options de lancement → colle :
       WINEDLLOVERRIDES="xinput1_4=n,b" %command%
   (à faire une seule fois)
7. Clique « Générer la seed », puis lance le jeu : NOUVELLE PARTIE, CHRIS, NORMAL.

VÉRIFIER QUE ÇA MARCHE
Après avoir ramassé un objet, le bouton « Journal du jeu » (onglet « Aider le projet »)
doit montrer « Point d'arret pose » puis « objet remplace ». La version Linux / Proton n'a pas
encore été confirmée sur un vrai Steam Deck : envoie ce journal, qu'il marche ou non !

REVENIR AU JEU NORMAL
« Désinstaller la DLL » dans l'application, et retire l'option de lancement dans Steam.
